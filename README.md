# Portfolio — Erika Milevskaya

Personal portfolio website for a web developer.

## Tech Stack

Next.js, React, TypeScript, CSS Modules, EmailJS

## Features

- Static Site Generation (SSG)
- Responsive design
- CSS animations
- Contact form with EmailJS
- Mobile burger menu

## Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev 
```

Fill in your EmailJS credentials in .env.local
